# Walmart Sales Intelligence Platform 🛒

> **An end-to-end, production-grade Data Science & Engineering project** combining a modular ETL pipeline, advanced SQL analytics, machine learning (clustering & forecasting), and an interactive Streamlit web dashboard — built on 10,000 Walmart sales transactions across 100 branches spanning 5 years (2019–2023).

## ⚙️ Getting Started

### Prerequisites
- Python 3.8+
- Docker & Docker Compose *(optional, for containerized database)*
- Git

### Step 1 — Clone & Install Dependencies
```bash
git clone https://github.com/YOUR_USERNAME/Walmart_SQL_Python.git
cd Walmart_SQL_Python
pip install -r requirements.txt
```

### Step 2 — Configure Environment Variables
```bash
cp .env.example .env
# Edit .env with your database credentials
```

### Step 3 — Spin Up Database (Docker)
```bash
docker compose up -d
# PostgreSQL → localhost:5432
# pgAdmin UI → http://localhost:8080
```

### Step 4 — Run the ETL Pipeline
```bash
python run_etl.py
```
This will:
- Extract raw data from `Walmart.csv` (10,051 records)
- Remove 51 duplicates and 31 null rows
- Convert currency strings (`$74.69`) to floats
- Calculate `total` revenue column
- Save `walmart_cleaned.csv` locally
- Load into PostgreSQL/MySQL (gracefully skips if DB is offline)

### Step 5 — Train the Machine Learning Models
```bash
python run_modeling.py
```
This will:
- Cluster 100 branches into **4 performance cohorts** using K-Means
- Train an **XGBoost sales forecaster** (train: 2019-2022, test: 2023)
- Save model binaries to the `models/` directory
- Export `walmart_clustered_branches.csv` and `walmart_forecast_eval.csv`

### Step 6 — Run the Interactive Dashboard
```bash
streamlit run app.py
```

### Step 7 — Run Unit Tests
```bash
python -m pytest tests/
```

## 📊 Dashboard Pages

### 📊 Executive Overview
Interactive KPI metrics (Total Revenue, Estimated Profit, Avg Rating, Transactions) with dynamic filters for Date Range, Category, and Payment Method. Includes monthly trends, payment method share donut chart, and category revenue horizontal bar chart.

### 📈 Sales Forecasting
Select any product category and view the XGBoost model's 2023 weekly sales predictions vs actual values. Displays per-category RMSE and MAPE performance metrics.

### 🏷️ Market Segments (Branch Clustering)
K-Means cluster visualization showing 100 branches grouped into 4 performance cohorts. Interactive scatter plot (Revenue vs. Rating colored by cluster) with cluster profile descriptions.

### 🎯 Price Elasticity Simulator
Adjust pricing from -20% to +20% and instantly see projected changes in sales volume and total revenue based on category-specific price elasticity coefficients.

## 🗄️ SQL Business Queries (9 Solved)

The file [`MySQL Queries.sql`](MySQL%20Queries.sql) contains solutions to 9 real business problems:

1. Payment method distribution & transaction volumes
2. Highest-rated product category per branch (Window Functions)
3. Busiest transaction day per branch (DAYNAME + RANK)
4. Total quantity sold by payment method
5. Rating statistics (min/max/avg) per city and category
6. Total profit per product category
7. Most common payment method per branch (CTE + RANK)
8. Sales shift breakdown — Morning / Afternoon / Evening
9. Top 5 branches with highest revenue decline YoY (2022 → 2023)

## 📈 Key Insights

- **Food & Beverages** generates the highest total revenue across all branches
- **Electronic accessories** have the highest price elasticity — pricing decisions have large demand impact
- **Saturday** is consistently the busiest sales day across branches
- **E-wallet** is the most preferred payment method overall
- **Cluster 2** branches (17 branches) show premium high-rating characteristics despite lower volume

## 🌐 Deploying the Dashboard

### Option A — Streamlit Community Cloud (Free)
1. Push your project to a public GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub
3. Click **"New App"** → Select your repo, branch (`main`), and set the main file as `app.py`
4. Add your environment variables under **"Advanced settings → Secrets"**
5. Click **Deploy** — your app will be live at `https://YOUR_APP.streamlit.app`

### Option B — Render (Free Tier)
1. Go to [render.com](https://render.com) and connect your GitHub repo
2. Create a **New Web Service** → Set build command: `pip install -r requirements.txt`
3. Set start command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
4. Deploy — available at `https://YOUR_APP.onrender.com`
